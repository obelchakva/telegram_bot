# Бот для просмотра тестов

## Структура папок для тестов
```
bot_data/
├── 1000/ # Номер задачи
│ ├── task_info.txt # Описание задачи (при наличии)
│ └── tests/ # Тесты
│ ├── 1 # Входные данные теста 1
│ ├── 1.a # Ожидаемый вывод теста 1
│ ├── 1.comment # Комментарий к тесту 1 (при наличии)
│ ├── 2
│ ├── 2.a
│ ├── 2.comment
│ └── ...
├── 1001/
└── ...
```

## Формат файлов:

### task_info.txt (пример оформления)

Название задачи
URL задачи на Информатиксе

Условие задачи (краткое описание)

Пример 1:
Вход: ...
Выход: ...

Пример 2:
Вход: ...
Выход: ...
text


### Файлы тестов:
- `N` - входные данные теста N
- `N.a` - ожидаемый вывод теста N  
- `N.comment` - комментарий преподавателя (необязательно)

## Загрузка тестов:
1. Создайте папку с номером задачи в `bot_data/`
2. Добавьте файл `task_info.txt` с описанием (необязательно)
3. Создайте папку `tests/`
4. Добавьте файлы тестов (1, 1.a, 2, 2.a, и т.д.)
5. При необходимости добавьте файлы `.comment` с комментариями (это можно сделать и через бота)

## Запуск бота:
```
pip install -r requirements.txt
python bot.py
```

## Преимущества нового решения:

1. **Простая загрузка тестов** - через файловую систему
2. **Комментарии к тестам** - отдельные файлы `.comment`
3. **Удобный интерфейс** - кнопочное меню

# Инструкция по установке и запуску

## Ubuntu/Linux
```
# Обновление пакетов (1)
sudo apt update

# Установка Python3 и pip (2)
sudo apt install python3 python3-pip python3-venv -y

# Проверка установки (3)
python3 --version
pip3 --version

# Переход в папку с ботом (4)
cd /путь/к/папке/с/ботом

# Создание виртуального окружения (5)
python3 -m venv bot_env

# Активация виртуального окружения (6)
source bot_env/bin/activate

# Проверка - в начале строки должно быть (bot_env) (6)

# Обновление pip (7)
pip install --upgrade pip

# Установка зависимостей из requirements.txt (8)
pip install -r requirements.txt

# Запуск основного файла (9)
python3 main.py
```
Шаги 1 - 3, 5, 7, 8 необходимо проделать один раз.
Шаги 4, 6 и 9 выполняются при каждом запуске бота.
